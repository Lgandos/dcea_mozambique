DCEA Mozambique: Malaria Interventions & Health Equity
Thesis: Leandro Gandos Brito, Swiss TPH / University of Basel, 2026

Overview
Distributional cost-effectiveness analysis (DCEA) of malaria interventions in Mozambique, disaggregated by wealth quintile using DHS 2022-23 microdata. Applies Atkinson inequality-aversion framework (Dawkins et al. 2018 methodology).
